## Что это

BilimCalc я начал делать потому, что каждую четверть вручную считать ФО/СОР/СОЧ в обычном калькуляторе — раздражает, а все онлайн-калькуляторы, которые я находил, были либо сломаны, либо завалены попапами, либо просто считали неправильно. Так что я сделал свой, который считает по реальной методике МОН РК и не просит регистрацию.

Со временем из одного калькулятора выросло три приложения на одной кодовой базе:

- **BilimCalc** — исходный: вводишь ФО, СОР и СОЧ, сразу получаешь оценку за четверть, плюс график динамики (по сути линейная регрессия), если накопилось хотя бы пара оценок ФО.
- **BilimExam** — для 9 и 11 класса. Берёт четыре четвертные оценки и оценку за экзамен и считает итоговую годовую по формуле 70/30, которая идёт в аттестат.
- **BilimGrant** — грубая оценка вероятности гранта ЕНТ по порогам программы, типу вуза и сельской квоте.

Все три — по ощущениям статичные одностраничники, которые отдаёт небольшой Flask-бэкенд, задеплоенный на Vercel.

## Почему это не просто форма с формулой

Несколько вещей, о которых я думал, пока это делал:

- **Должно работать офлайн.** Есть service worker, который кэширует оболочку приложения и страницы — если у школьника плохой вайфай в школе, сайт всё равно откроется и посчитает локально.
- **Должно работать на разбитом Android 2019 года.** Никаких фреймворков и сборки, чистый JS. Мобильная вёрстка подгонялась руками, а не просто «responsive по умолчанию».
- **Запоминает введённое.** Всё сохраняется в `localStorage`, чтобы не терять цифры при обновлении страницы — на сервер ничего не уходит.
- **Двуязычный.** Полный перевод на русский и казахский, баннер с предложением переключить язык по языку браузера, и роутинг локали через URL (`/kk/...`).
- **Устанавливается как приложение.** PWA-манифест и промпты на установку — для Android через `beforeinstallprompt`, для iOS вручную (инструкция «Добавить на экран Домой», потому что Safari не поддерживает API).

## Блог

Ещё есть набор статей — разбор методики, как считаются ФО/СОР/СОЧ, формула 70/30, пороги гранта ЕНТ, комбинации профильных предметов, факт-чек слухов про переход на 12-летку — написанных так, чтобы реально быть полезными, с разметкой schema.org, RSS-лентой, sitemap и файлом `llms.txt` для тех, чей ИИ-краулер хочет получить чистое summary вместо парсинга HTML.

## Как это окупается

Сайт живёт на рекламных блоках Яндекса (внутристатейные слоты, липкий баннер снизу, пара десктопных боковых панелей) плюс Яндекс.Метрика и GA4 для базовой статистики. Есть честный скрипт детекции адблока — пять эвристик голосуют вместе — который показывает небольшой баннер с просьбой добавить сайт в исключения, и страницу с пошаговой инструкцией, как это сделать, если человек захочет помочь. Если не захочет — сайт всё равно работает точно так же, ничего не закрыто пейволлом.

## Стек

**Бэкенд**
- Python 3.11, Flask, Gunicorn
- Шаблоны Jinja2, i18n на стороне сервера (без клиентской библиотеки перевода)
- Supabase — только для одной вещи: счётчика посетителей

**Фронтенд**
- Чистый JS, без сборки
- Chart.js (ленивая загрузка) для графиков динамики
- Ручной CSS, тёмная/светлая тема с фолбэком на `prefers-color-scheme`

**Инфра**
- Vercel для хостинга
- Service worker для офлайн-кэша
- Пинг IndexNow при деплое, чтобы поисковики быстрее подхватывали изменения

## Запуск локально

```bash
git clone https://github.com/antonbogdan165/BilimCalc.git
cd BilimCalc
pip install -r requirements.txt
python app.py
```

Дальше открой `http://127.0.0.1:5000`. Если хочешь, чтобы реклама, аналитика и счётчик посетителей реально работали — заполни переменные окружения (см. `config.py`); для самих калькуляторов они не нужны.
